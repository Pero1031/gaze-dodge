# 画像の障害物

このフォルダに画像を置き、`obstacles.json` に書き足すと、その画像が障害物として出てきます。

**このフォルダの画像と `obstacles.json` は GitHub に載せません**（`.gitignore` で除外。この README だけ管理対象）。
別の PC で使うときは、画像と `obstacles.json` を手でコピーしてください。

## 手順

1. 画像をこのフォルダに置く（PNG・WebP・SVG・JPG）
   - 背景が透明な PNG / SVG なら、`"hitbox": "alpha"` で透明な部分を当たり判定から外せます
   - 大きさは何でもよい（ゲーム側で `size` に合わせて縮小・拡大します）。512 px 四方程度までなら軽く動きます
2. `obstacles.json` の `images` に追加する
3. ブラウザでゲームを読み込み直す（ブリッジの再起動は不要）

## obstacles.json の例

```json
{
  "images": [
    {
      "file": "anime_prof.PNG",
      "probability": 0.10,
      "size": [80, 100],
      "hitbox": "circle",
      "spin": false,
      "fall_speed": [70, 100],
      "homing_speed": 120
    }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `file` | このフォルダ内のファイル名（大文字・小文字も合わせる） |
| `probability` | 障害物を 1 つ出すとき、この画像になる確率（**全障害物のうちの割合**。0.10 なら 10%）。選ばれなければ岩か横バーになる。複数の画像の合計が 1 を超えたら比率を保って縮める |
| `size` | 表示する幅 [px]。`[最小, 最大]` でその範囲からランダム、数値 1 つなら固定。高さは縦横比から決まる |
| `hitbox` | 当たり判定。`"alpha"`＝不透明な部分だけ（形どおり）、`"circle"`＝画像に内接する円、`"box"`＝画像の四角形全体 |
| `spin` | `true` で回転しながら落ちる |
| `fall_speed` | 落ちる速さ [px/s]（`[最小, 最大]` か数値）。省略すると岩と同じ（160〜300）。時間とともに岩と同じ割合で速くなる |
| `homing_speed` | プレイヤーに**横から寄っていく**最大の速さ [px/s]。0 か省略で寄らない。縦は常に下向きで上には動かず、プレイヤーより下に来たら追うのをやめてそのまま下へ消える |

見本の `sample_meteor.svg`（紫の隕石、形どおりの当たり判定・回転）を使う場合の例：

```json
{ "file": "sample_meteor.svg", "probability": 0.1, "size": [60, 110], "hitbox": "alpha", "spin": true }
```

## 注意

- ゲームを `http://localhost:8000`（`run_tobii.bat` / `tobii_bridge.py`）で開いたときだけ読み込まれます。
  `index.html` を直接ダブルクリックで開いた場合は、ブラウザの制限で設定ファイルを読めないため、画像の障害物は出ません
- `obstacles.json` の書式やファイル名が間違っていると画像の障害物は出ず、画面左下に理由が表示されます
- 視線で操作するゲームなので、**目を引く画像（特に顔）ほど見てしまい、プレイヤーが画像に吸い寄せられて当たりやすくなります**。
  `homing_speed` で寄ってくる障害物は、見てしまう＋寄ってくるの組み合わせでかなり手強くなります
