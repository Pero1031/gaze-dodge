# 画像の障害物

このフォルダに画像を置き、`obstacles.json` に書き足すと、ゲーム中の「岩（丸い障害物）」の一部がその画像に置き換わります。
横バーはそのままです。

## 手順

1. 画像をこのフォルダに置く（PNG・WebP・SVG・JPG）
   - **背景が透明な PNG / SVG がおすすめ**です。透明な部分は当たり判定に入りません
   - 大きさは何でもよい（ゲーム側で `size` に合わせて縮小・拡大します）。512 px 四方程度までなら軽く動きます
2. `obstacles.json` の `images` に 1 行追加する
3. ブラウザでゲームを読み込み直す（ブリッジの再起動は不要）

## obstacles.json の項目

```json
{
  "probability": 0.3,
  "images": [
    { "file": "sample_meteor.svg", "size": [60, 110], "weight": 1, "hitbox": "alpha", "spin": true }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `probability` | 岩の代わりに画像が出る割合（0〜1）。`0` にすると画像の障害物は出ない |
| `file` | このフォルダ内のファイル名 |
| `size` | 表示する幅 [px]。`[最小, 最大]` でその範囲からランダム、数値 1 つなら固定。高さは縦横比から決まる |
| `weight` | 複数の画像のうち、どれが出やすいか（相対的な重み。2 なら 1 の 2 倍出る） |
| `hitbox` | 当たり判定。`"alpha"`＝不透明な部分だけ（形どおり）、`"circle"`＝画像に内接する円、`"box"`＝画像の四角形全体 |
| `spin` | `true` で回転しながら落ちる |

見本の `sample_meteor.svg` が不要なら、`images` から行を消すか、ファイルごと削除してください。

## 注意

- ゲームを `http://localhost:8000`（`run_tobii.bat` / `tobii_bridge.py`）で開いたときだけ読み込まれます。
  `index.html` を直接ダブルクリックで開いた場合は、ブラウザの制限で設定ファイルを読めないため、画像の障害物は出ません
- `obstacles.json` の書式が間違っていると画像の障害物は出ず、画面左下に理由が表示されます
- 視線で操作するゲームなので、**目を引く画像ほど見てしまい、プレイヤーが画像に吸い寄せられて当たりやすくなります**。
  顔・文字・明るく派手な画像は難易度が上がる点に注意してください（逆にそれを狙った障害物にもできます）
